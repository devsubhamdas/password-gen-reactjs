# Password Generator

A simple and responsive **Password Generator** built with **React** and **Vite**. It allows users to generate secure passwords with different combinations of characters.

## 🚀 Live Demo

https://devsubhamdas.github.io/password-gen-reactjs

## 🛠️ Tech Stack

* React
* Vite
* JavaScript
* Tailwind CSS
* ESLint

## 📦 Project Setup

### 1. Clone the repository

```bash
git clone https://github.com/devsubhamdas/password-gen-reactjs
cd password-gen-reactjs
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at the local URL shown in the terminal.

### 4. Build for production

```bash
npm run build
```

### 5. Preview the production build

```bash
npm run preview
```
